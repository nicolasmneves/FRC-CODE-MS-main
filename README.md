# 01-frc

> **Repositório arquivado.** Esta é uma versão anterior do código do robô. A versão atual está em [FRC-CODE-MS-main](https://github.com/nicolasmneves/FRC-CODE-MS-main).

Código FRC em Java (WPILib 2026) com:

- **Swerve drive** usando YAGSL, com configurações para módulos NEO, Falcon e MAXSwerve
- **Garra**: intake e punho (`subsystems/garra`)
- **Elevador** (`ElevadorSubsystem`)
- **Autônomo** com PathPlanner e comando de autobalance

## Como rodar

Abra a pasta no **WPILib VS Code** e rode:

```
./gradlew build
./gradlew deploy
```
